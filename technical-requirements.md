# TECHNICAL REQUIREMENTS

## SHARED

- menu icon is a hamburger menu in closed state
- the hamburger icon changes to an X icon when menu is open
- when you first navigate to the page the menu is in the top left corner and none of the links are visible
- menu is on all pages
- menus on desktop and mobile can also be closed by clicking outside the container
- links become visible when you click on the menu icon
- the menu is returned to its closed state when clicking the menu icon
- the container is on top of the content
- the menu is part of a sticky navbar
- the sticky navbar gets a drop shadow once it's no longer at the top of the page

## DESKTOP

- on desktop container for the menu links appears on the left side of the screen

## MOBILE/TABLET

- the container with the links on mobile is viewport width

# TECHNICAL DESIGN

## Overview

The website will have a menu that is shared across all pages and contains links to all the pages on the site. The menu will have somewhat different styling on desktop and mobile.

## High Level Design

The menu will be a web component so it can be shared across all pages on the site. It has an open state and a closed state. In its closed state it's a hamburger menu and in its open state it's a collection of links and a close button. The menu will stick to the top of the screen and will use media queries to control desktop vs mobile styling.
